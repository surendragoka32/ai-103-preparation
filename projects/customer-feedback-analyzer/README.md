# AI-103 Project: Customer Feedback Analyzer

A beginner-friendly Python project that uses **Azure AI Language** to classify customer reviews as positive, negative, or neutral and show confidence scores.

## AI-103 concepts practised
- AI workload selection: text analysis / sentiment analysis
- Azure AI Language resource, endpoint, and region
- Authentication with an API key (learning/demo setup only)
- Keeping secrets in environment variables and excluding them from Git
- Identity and access concepts: Microsoft Entra ID, RBAC, least privilege, and Managed Identity (production upgrade topics)

## Architecture

```text
Customer review -> Python app -> Azure AI Language -> Sentiment + confidence scores
```

## 1. Create the Azure resource
1. In the Azure portal, create an **Azure AI Language** resource.
2. Note its endpoint and one key from **Keys and Endpoint**.
3. The resource must be available in your Azure subscription. Free pricing availability can vary by region/subscription.

## 2. Set up Python
Python 3.9+ is recommended.

```bash
python -m venv .venv
```

Activate the virtual environment:
- Windows: `.venv\\Scripts\\activate`
- macOS/Linux: `source .venv/bin/activate`

Install dependencies:

```bash
pip install -r requirements.txt
```

## 3. Configure environment variables
Copy `.env.example` to `.env` and fill in your own endpoint and key. Never commit `.env`.

Example format (placeholders only):

```text
LANGUAGE_ENDPOINT=https://YOUR-RESOURCE.cognitiveservices.azure.com/
LANGUAGE_KEY=YOUR_KEY_HERE
```

## 4. Run the app

```bash
python app.py
```

Try:
- `The product is excellent and delivery was very fast.`
- `The product is terrible and I am very disappointed.`
- `The product arrived today.`

The exact sentiment and confidence scores are generated by the live service and may vary.

## Security note
This learning version uses an API key stored in a local `.env` file. The `.env` file is ignored by Git. For a production Azure-hosted app, prefer Microsoft Entra ID with Managed Identity and grant only the required permissions. Do not paste real keys into source code, screenshots, issues, or GitHub.

## Current scope
This repository contains the project code and instructions. It does not create Azure resources automatically, and the app has not been run against your Azure subscription from this repository.
